## Project Overview
The Food Ordering System is a simple web-based application that allows customers to browse a restaurant's menu, place food orders online, and track their order status, while giving staff a way to manage and update incoming orders.

## Problem Statement
Customers have difficulty browsing menu items, placing food orders, and tracking their order status, while staff struggle to manage incoming orders manually.

## Target Users
Customers and restaurant staff.

## Main Features
1. Browse menu items.
2. Place a new order.
3. View order status.
4. Update order status (staff).
5. Cancel an order.

## Proposed Technology Stack
- Frontend: Vue.js
- Backend: Node.js and Express
- Database: MongoDB Atlas Free
- Version Control: Git and GitHub
